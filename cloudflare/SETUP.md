# Как включить загрузку видео на всех устройствах

Сайт остается на GitHub Pages, а **видео хранятся в отдельном Cloudflare R2**. Загрузку можно запускать прямо на странице «Свадебный ролик» и в любом из 16 разделов «Интервью». Файлы загружаются по частям, поэтому подходят и длинные ролики.

## Настройка Cloudflare (один раз)

1. Откройте https://dash.cloudflare.com и создайте аккаунт или войдите.
2. Выберите **Storage & databases → R2 → Overview**. Если R2 ещё не активирован, выполните шаги оформления подписки (Cloudflare может запросить платёжные данные). Наличие бесплатного лимита **не гарантирует отсутствие платы при превышении лимитов**.
3. Создайте R2 bucket с названием **golden-wedding-50-videos**, тип хранения **Standard**. Не включайте публичный домен на самом bucket.
4. Откройте **Workers & Pages → Create → Worker**, задайте имя **golden-wedding-media** и создайте Worker.
5. В редакторе Worker замените демонстрационный код содержимым файла **cloudflare/worker.js** из этого репозитория. Нажмите **Deploy**.
6. В настройках Worker, в разделе **Bindings**, добавьте тип **R2 bucket**. Имя переменной должно быть строго **WEDDING_MEDIA**; выберите bucket **golden-wedding-50-videos**. Сохраните и разверните изменения.
7. В настройках Worker → **Variables and Secrets** добавьте переменную типа **Secret** с именем **ADMIN_TOKEN**. Значение — сложный случайный пароль **не короче 24 символов**. Сохраните его у себя. **Никогда не присылайте пароль в чат и не публикуйте его в GitHub.**
8. Откройте URL своего Worker с окончанием **/health**. Должен появиться JSON с **ok: true**.
9. Передайте в чат **только публичный адрес Worker**, например `https://golden-wedding-media.example.workers.dev`. Ассистент впишет этот адрес в файл **cloud-media-config.js** и выгрузит обновление в GitHub.

После настройки сайт сам получает список видео. На первом выборе видео потребуется ввести **ADMIN_TOKEN** — он хранится только в памяти открытой вкладки (повторно потребуется после её закрытия). Затем каждое следующее видео можно загрузить обычной кнопкой «Выбрать видео». Статус загрузки виден на экране.

## Где сохраняются видео

- Свадебный ролик — ключ `wedding`.
- 16 интервью — ключи `interview-0` … `interview-15`.
- Повторная загрузка в тот же раздел заменяет его видео.
- Другие устройства автоматически перечитывают список примерно каждые 30 секунд, а при открытии страницы — сразу.
- Надёжный формат для просмотра на ноутбуках и ТВ: **MP4 с H.264 и AAC**. MOV/WebM могут не воспроизводиться в отдельных браузерах.
- Перед праздником проверьте видео и звук на реальном ноутбуке, которым будете пользоваться, и подготовьте резервную локальную копию. Для доступа к R2 нужен интернет.

## Приватность

**Очень важно:** хотя сам R2 bucket закрыт от прямого доступа, Worker в текущем варианте разрешает воспроизведение видео без входа в аккаунт. Каждый, кто знает адрес сайта или ссылки на файлы, сможет смотреть семейные видеоролики. Для полностью семейного закрытого доступа понадобится отдельный режим авторизации гостей, который ещё не реализован. Не загружайте личные видео без согласия участников.

## Лимиты

На ноябрь 2026 Cloudflare R2 для класса Standard предоставляет **10 ГБ-месяцев** и некоторое количество операций бесплатно, но для начала работы Cloudflare требует активировать R2, а превышение квот может быть платным. Длинные видео отправляются частями по 8 МиБ. Смотрите актуальные лимиты на https://developers.cloudflare.com/r2/pricing/.

## Проверка

1. Выберите видео в разделе «Свадебный ролик».
2. Введите свой секретный код администратора.
3. Дождитесь надписи **«Готово! Видео доступно на всех устройствах.»**
4. Откройте тот же сайт на ноутбуке или телефоне; видео появится после загрузки списка.

Если статус пишет «Хранилище ещё не подключено», значит адрес Cloudflare Worker в **cloud-media-config.js** ещё пустой. До этого момента загрузка видео через сайт **заблокирована**, чтобы случайно не потерять файлы.
