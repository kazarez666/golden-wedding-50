# Бесплатная загрузка видео и музыки на все устройства (Cloudinary Free)

**Сайт уже настроен:** Cloud name `t8dsuxni`, Upload Preset `wedding_video_free`. Новый аккаунт и новый preset не нужны. Чтобы с сайта загружались MP3, нужно разрешить формат mp3 в действующем preset.

## Один обязательный шаг для MP3

1. Откройте Cloudinary → **Settings → Upload → Upload Presets**.
2. Откройте уже созданный **`wedding_video_free`**.
3. Найдите **Allowed formats** (разрешённые форматы). Оставьте **mp4** и добавьте **mp3**. Не выбирайте платные дополнения.
4. Нажмите **Save**. Если вы не задавали ограничения форматов, специально менять их не требуется.
5. На [сайте золотой свадьбы](https://kazarez666.github.io/golden-wedding-50/) откройте «Торжественная встреча» и выберите тестовый MP3. После загрузки проверьте, что он воспроизводится на другом устройстве. Также протестируйте один пункт раздела «Угадай мелодию».

Cloudinary хранит **MP3 как video resource**, поэтому в коде тот же адрес загрузки `/video/upload` и тот же общий список, что и для свадебного видео и 16 интервью. Синхронизация обычно занимает до 60 секунд.

**Поддерживаемые слоты:** свадебный MP4, 16 интервью MP4, MP3 марша Мендельсона и 8 MP3 из «Угадай мелодию». Данные загружаются на Cloudinary напрямую из браузера, а не в GitHub. Для работы на втором устройстве требуется интернет.

**Ограничения:** 100 МБ на файл на бесплатном тарифе; использование хранилища, трафика и преобразований учитывается в бесплатном лимите. Тест лучше проводить на небольших файлах. Звук сохраняется в облаке, но права на чужие музыкальные записи должны соблюдаться.

**Конфиденциальность:** текущая схема использует публичные ссылки и открытый unsigned preset. Файлы доступны обладателям ссылок; настройки загрузки из публичного сайта можно увидеть. Не загружайте конфиденциальные материалы без отдельной защиты сервера. После окончания загрузок можно отключить unsigned preset, не удаляя уже загруженные записи.

**Если файл не появляется на другом устройстве:** проверьте **Settings → Security → Restricted image types → Resource list**: публичные списки должны быть разрешены, иначе статический сайт не сможет получить перечень загруженных файлов. Это делает список по известному тегу доступным извне.

## Что получится

Нажимаете на сайте «Выбрать свадебное видео» или «Выбрать видео для этого интервью» → выбираете MP4 → дожидаетесь окончания загрузки → запись сохраняется в Cloudinary и появляется на ноутбуке, компьютере и телефоне. Другие устройства проверяют список примерно раз в 30 секунд. Cloudinary может обновлять список до 60 секунд.

**Стоимость:** тариф **Free ($0)**, без банковской карты; 25 кредитов на хранение, обработку и отдачу файлов за месяц. На бесплатном тарифе максимум **100 МБ на один видеофайл**. Если общий объём 500 МБ, хранение ориентировочно расходует около 0,5 кредита, но просмотры расходуют трафик (1 ГБ видео — 1 кредит), а обработка также учитывается. Смотрите статистику в консоли Cloudinary.

⚠ **Важное ограничение безопасности:** этот упрощённый вариант использует unsigned upload preset и публичный список ресурсов. Ролики доступны любому, кто получит ссылку; известный стороннему человеку upload preset может позволить загружать файлы в ваш аккаунт. Это решение **не подходит для закрытого семейного архива**. Не загружайте личные записи, пока участники не согласны на публикацию. После завершения всех загрузок можно отключить unsigned preset в настройках Cloudinary, оставив просмотр. Для по-настоящему приватного хранения нужен сервер с авторизацией.

## Настройка (один раз)

1. Зарегистрируйтесь на **https://cloudinary.com/pricing** — выберите **Free ($0)**, без ввода банковской карты. Не выбирайте платные планы.
2. На главной странице консоли найдите **Cloud name**. Это короткое название окружения, например `mycloud123`; **API Key и API Secret никому не пересылайте**.
3. Откройте **Settings → Upload → Upload Presets → Add Upload Preset**. Создайте новый preset с режимом **Unsigned**. Задайте имя, например `wedding_video_free`, и ограничьте допустимый формат **MP4**. Включите **Disallow public ID**, чтобы нельзя было перезаписывать видео через upload preset. Сохраните preset.
4. Откройте **Settings → Security → Restricted image types**. Для клиентского списка видео снимите ограничение **Resource list**. Без этого другие устройства не смогут увидеть общий список через статический GitHub Pages. Учитывайте, что это делает списки с известными тегами публично доступными.
5. Откройте файл [`cloud-media-config.js`](cloud-media-config.js) в GitHub и нажмите значок карандаша (Edit this file). Заполните **только** эти значения:

   ```js
   cloudName: 'ВАШ_CLOUD_NAME',
   uploadPreset: 'ИМЯ_UNSIGNED_PRESET',
   ```

   Не меняйте поле `tag`; оно связывает видео между устройствами. Нажмите **Commit changes**.

6. После публикации GitHub Pages откройте сайт [golden-wedding-50](https://kazarez666.github.io/golden-wedding-50/), выберите любое интервью и загрузите тестовый MP4 размером до 100 МБ. Дождитесь сообщения об успешной загрузке. Откройте тот же раздел на другом устройстве; при необходимости обновите страницу. Иногда синхронизация занимает до минуты.
7. Когда убедитесь, что тест работает, загружайте остальные записи по их соответствующим номерам. Свадебный ролик загружайте в разделе «Свадебный ролик».

## Важно

- Загрузка на сайте не включится, пока `cloudName` и `uploadPreset` пусты. Это сделано специально, чтобы видео не оставались только во временной памяти браузера.
- Бесплатный тариф ограничен 100 МБ **на файл**. Файл 150 МБ не загрузится, даже если на аккаунте свободно 500 МБ.
- Лучше MP4 с кодеками H.264 + AAC — для Opera, Chrome, Яндекс Браузера и большинства телевизоров.
- Если нужно заменить видео, загрузите новый MP4 в тот же раздел. Сайт выберет последнюю версию, но предыдущая останется в Cloudinary и будет занимать место — её нужно удалить вручную через Media Library.
- После праздника рекомендую отключить или удалить unsigned preset, чтобы посторонние не использовали вашу квоту.
- Никакие API Secret, пароли, ключи администратора или банковские данные в публичный GitHub не добавляйте.
