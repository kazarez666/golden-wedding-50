# Загрузка видео и MP3 на все устройства — Cloudinary Free

В репозитории уже указаны **Cloud name `t8dsuxni`** и **Upload Preset `wedding_video_free`**. Сайт остаётся на GitHub Pages. Для постоянного хранения файлов используется бесплатный тариф Cloudinary.

## Разрешите MP3 и изображения для конкурса «Силуэты»

Откройте **Cloudinary → Settings → Upload → Upload Presets → `wedding_video_free`**. В разделе **Allowed formats / Разрешённые форматы** укажите **`mp4,mp3,jpg,jpeg,png,webp`**, сохраняя MP4 и MP3 и разрешая свои изображения. Нажмите **Save**. Если список разрешённых форматов пуст (нет ограничения), специально менять его не нужно. Не включайте платные функции.

Cloudinary хранит MP4 и MP3 как тип ресурса `video`, а картинки силуэтов — как `image`. Для всех используется тот же Upload Preset, новую учётную запись создавать не требуется.

## Загрузка медиа и режим праздника

На праздничных экранах нет технических кнопок загрузки для **марша Мендельсона, интервью и силуэтов**. Для **свадебного ролика** кнопку «Загрузить свадебный ролик» вернули — запись ещё предстоит добавить. Ранее загруженные файлы продолжают воспроизводиться по прежним облачным слотам.

В разделе **«Продолжи песню»** сохранены 20 музыкальных позиций с загрузкой MP3 через «⚙ Настройка песни и фрагмента», регулировкой громкости и метками куплета и припева. Запись загружается на каждую позицию отдельно. Метки и введённые ответы хранятся в браузере, пока не перенесены в `data.js`.

Для остальных типов файлов замена требует загрузки в Cloudinary с прежним тегом `golden_wedding_50_family_2026` и соответствующим контекстом `slot` (`march`, `wedding`, `interview-0`…`interview-15`, `silhouette-0`, `silhouette-1`). Обычная загрузка без этих полей не привяжет файл к нужному этапу. Перед праздником проверьте доступность всех медиа и звук с телевизора.

Важные ограничения: **100 МБ на видео/аудио и 10 МБ на изображение**. Хранение и трафик засчитываются в лимит аккаунта. Повторная загрузка на прежний слот не удаляет старые записи из Cloudinary.

## Если не появляется на другом устройстве

Проверьте **Cloudinary → Settings → Security → Restricted image types → Resource list**. Для чтения общего списка файлов с публичного GitHub Pages нужно разрешить **Resource list**. В противном случае загрузка может пройти успешно, но на другом устройстве ничего не появится.

## Конфиденциальность и права

Текущая интеграция использует публичные адреса файлов и unsigned upload preset. Она **не является приватным семейным архивом**: обладатель ссылки может просматривать файл, а открытый preset может использовать посторонний для загрузки за счёт вашего лимита. Для закрытых семейных видео необходима серверная авторизация. После окончательной загрузки файлов рекомендуется отключить unsigned preset, оставив воспроизведение. Для загружаемых музыкальных записей учитывайте авторские права и права исполнителей.

Никогда не добавляйте API Key, API Secret или пароли в публичный GitHub.
