# Золотая свадьба — Павел Семёнович и Ольга Леонидовна

**Актуальная версия 1.0: бургунди / кремовый / золотой, 10 согласованных фильмов, синхронизация MP3 и видео.** Интерактивная программа праздника для показа с ноутбука на телевизоре через HDMI. Сайт полностью статический: `index.html`, `styles.css`, `data.js`, `app.js`, папки `assets/` и `media/`. Не требуются npm, аккаунт или платный хостинг.

## Посмотреть сейчас

1. Откройте опубликованный сайт: https://kazarez666.github.io/golden-wedding-50/.
2. Для настоящего праздника используйте ноутбук и телевизор через HDMI; облачным файлам нужен интернет.
3. Нажимайте этапы слева или используйте клавиши **←** и **→**.
4. Для показа на телевизоре нажмите **«Режим показа»** — меню исчезнет, и браузер попробует перейти на весь экран. Нажмите **H**, чтобы вернуть меню; клавиша **F** включает/выключает полноэкранный режим.
5. Подключите ноутбук к телевизору через HDMI и в настройках Windows выберите **Дублировать экраны**. Звук при необходимости переключите на телевизор в системных настройках.

## Как добавить видео, музыку и фотографии

Файлы **не включены** в демо. Для постоянной загрузки свадебного ролика и интервью с синхронизацией между устройствами предусмотрен [Cloudinary Free](CLOUDINARY_SETUP.md). Пока бесплатный аккаунт не настроен, выбор видео через сайт не сохраняется и не выполняется.

Для постоянной работы положите файлы в эти пути:

```
media/
  march.mp3                 — запись марша Мендельсона
  wedding.mp4               — свадебный ролик
  interviews/
    01.mp4 ... 16.mp4       — шестнадцать интервью
  melodies/
    01.mp3 ... 08.mp3       — восемь музыкальных фрагментов
  salads/
    01.jpg ... 05.jpg       — фото для конкурса «Салаты и закуски»
```

**Важно:** если меняете файлы или число вопросов, загляните в `data.js` — все названия и настройки находятся именно там. Желательный формат видео: MP4 (H.264 для изображения, AAC для звука); музыка — MP3. Для марша нужна запись, которую вы вправе использовать: музыкальное произведение Мендельсона находится в общественном достоянии, но права на конкретную запись могут сохраняться.

## Перед праздником

- Проводить проверку **в том же браузере, на том же ноутбуке, телевизоре и кабеле**, что будут использоваться на празднике.
- Проверить звук через телевизор до прихода гостей.
- Проверить воспроизведение и громкость всех 16 видео и музыкальных отрывков.
- Не полагаться на автозапуск музыки/видео: браузеры блокируют автоматическое воспроизведение со звуком. Всё запускается вручную.
- Если требуется полностью автономная работа без интернета — используйте распакованную папку с *всеми* локальными медиафайлами; сайт не загружает шрифты или код из интернета.

## GitHub

Для этого проекта нужен **отдельный репозиторий**, чтобы не затронуть другой сайт `anniversary-site` с поздравлением к первой годовщине. Опубликовать можно через GitHub Pages: репозиторий → **Settings → Pages → Deploy from a branch → main / (root) → Save**.

⚠️ GitHub Pages публичен. Прежде чем публиковать личные видеозаписи, фотографии и интервью, убедитесь, что участники согласны на их размещение в открытом доступе. Для семейного праздника безопаснее держать видео в локальной папке, а не загружать в публичный репозиторий.

## Синхронизация MP4 и MP3 — Cloudinary Free

На сайте уже указан Cloudinary Cloud name и существующий Upload Preset. Через кнопки можно загружать **свадебный MP4, 16 интервью MP4, MP3 марша и 8 MP3 музыкальной викторины**. Файлы должны появляться на всех устройствах после обновления списка Cloudinary (обычно до 60 секунд).

**Для MP3 в Cloudinary необходимо разрешить формат `mp3` в Upload Preset `wedding_video_free`, сохранив `mp4`.** Рекомендуемый предельный размер — 100 МБ на файл. Подробности и проверка описаны в [CLOUDINARY_SETUP.md](CLOUDINARY_SETUP.md).

⚠️ Самый простой вариант Cloudinary использует публичные ссылки и открытый preset для загрузки. Он не обеспечивает конфиденциальность личных семейных видео. Для приватного доступа понадобится отдельный авторизованный сервер. Старые файлы `cloudflare/` сохранены только как архив предыдущей идеи и не используются сайтом.
