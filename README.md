# Золотая свадьба — Павел Семёнович и Ольга Леонидовна

**Актуальная версия 2.5: бургунди / кремовый / золотой, 10 согласованных фильмов, 20 музыкальных заданий и синхронизация медиафайлов.** Интерактивная программа праздника для показа с ноутбука на телевизоре через HDMI. Сайт полностью статический: `index.html`, `styles.css`, `data.js`, `app.js`, папки `assets/` и `media/`. Не требуются npm, аккаунт или платный хостинг.

## Посмотреть сейчас

1. Откройте опубликованный сайт: https://kazarez666.github.io/golden-wedding-50/.
2. Для настоящего праздника используйте ноутбук и телевизор через HDMI; облачным файлам нужен интернет.
3. Нажимайте этапы слева или используйте клавиши **←** и **→**.
4. Для показа на телевизоре нажмите **«Режим показа»** — меню исчезнет, и браузер попробует перейти на весь экран. Нажмите **H**, чтобы вернуть меню; клавиша **F** включает/выключает полноэкранный режим.
5. Подключите ноутбук к телевизору через HDMI и в настройках Windows выберите **Дублировать экраны**. Звук при необходимости переключите на телевизор в системных настройках.

## Как добавить видео, музыку и фотографии

Файлы **не включены** в демо. Для постоянной загрузки свадебного ролика и интервью с синхронизацией между устройствами предусмотрен [Cloudinary Free](CLOUDINARY_SETUP.md). Пока бесплатный аккаунт не настроен, выбор видео через сайт не сохраняется и не выполняется.

Для постоянной работы положите файлы в эти пути:

```
media/
  march.mp3                 — запись марша Мендельсона
  wedding.mp4               — свадебный ролик
  interviews/
    01.mp4 ... 16.mp4       — шестнадцать интервью
  melodies/
    01.mp3 ... 20.mp3       — двадцать музыкальных фрагментов
```

**Важно:** если меняете файлы или число вопросов, загляните в `data.js` — все названия и настройки находятся именно там. Желательный формат видео: MP4 (H.264 для изображения, AAC для звука); музыка — MP3. Для марша нужна запись, которую вы вправе использовать: музыкальное произведение Мендельсона находится в общественном достоянии, но права на конкретную запись могут сохраняться.

## Перед праздником

- Проводить проверку **в том же браузере, на том же ноутбуке, телевизоре и кабеле**, что будут использоваться на празднике.
- Проверить звук через телевизор до прихода гостей.
- Проверить воспроизведение и громкость всех 16 видео и музыкальных отрывков.
- Не полагаться на автозапуск музыки/видео: браузеры блокируют автоматическое воспроизведение со звуком. Всё запускается вручную.
- Если требуется полностью автономная работа без интернета — используйте распакованную папку с *всеми* локальными медиафайлами; сайт не загружает шрифты или код из интернета.

## Синхронизация MP4, MP3 и двух картинок — Cloudinary Free

На сайте уже указан Cloudinary Cloud name и существующий Upload Preset. В праздничном интерфейсе сохранена загрузка **20 MP3 для «Продолжи песню»**. Кнопки настройки для марша, интервью и картинок силуэтов намеренно убраны; загрузка свадебного видео возвращена; сами Cloudinary-ссылки и воспроизведение продолжают работать. Файлы должны появляться на всех устройствах после обновления списка Cloudinary (обычно до 60 секунд).

**Для музыки и силуэтов в Cloudinary разрешите форматы `mp4,mp3,jpg,jpeg,png,webp` в Upload Preset `wedding_video_free`.** Рекомендуемый предельный размер — 100 МБ на файл. Подробности и проверка описаны в [CLOUDINARY_SETUP.md](CLOUDINARY_SETUP.md).

⚠️ Самый простой вариант Cloudinary использует публичные ссылки и открытый preset для загрузки. Он не обеспечивает конфиденциальность личных семейных видео. Для приватного доступа понадобится отдельный авторизованный сервер. Старые файлы `cloudflare/` сохранены только как архив предыдущей идеи и не используются сайтом.

## Визуальное управление (версия 1.1)

- Фоновая заставка: строго бургунди **снаружи** золотой рамки, кремовый **внутри** и ФИО бургунди. Палитра: `#3F010D`, `#FEF4DC`, `#D7B052`.
- В правом верхнем углу одна кнопка **«Управление»**: фон, полный экран, режим показа, подсказки. В режиме показа меню открывается кнопкой **☰** в нижнем блоке переключения.
- Раздел **«Силуэты»**: при наличии двух заранее загруженных изображений можно запускать 20-секундный показ, после которого картинка скрывается. После таймера доступна кнопка «Показать ответы» с количествами для каждого раунда. На праздничном слайде нет кнопок загрузки или технических инструкций.

## Предварительно выставленные моменты музыки

По доступным синхронизированным текстам песен автоматически определены **14 предварительных пар «куплет → припев»**. Эти секунды уже внесены в `data.js` и видны в настройках музыкального конкурса. Для шести оставшихся песен нет достоверной привязки: среди них запись без указания названия («Гости из будущего»), несколько песен без синхронизации нужного исполнения и песни без чётко выделенного припева.

**Подробный список с секундами и источниками:** [MELODY_CUES.md](MELODY_CUES.md). Все отметки пока **не проверены на конкретных MP3**. Если длительность загруженного файла отличается от источника, сайт предупредит об этом.

## Выбранные композиции — музыкальная викторина (20 песен)

Порядок перемешан и закреплён, чтобы загруженные записи не меняли свои позиции при каждом открытии. Исполнители и названия заданы в `data.js`; ведущий видит правильный ответ только после нажатия **«Показать ответ»**.

**Раунд 08:** пользователь назвал группу «Гости из будущего», но пока не указал композицию. Не выбирать название автоматически. Для остальных 19 песен ответы уже заполнены.

Все точки начала куплета и припева пока требуют проверки по конкретным аудиозаписям. Песни и временные метки в браузере — разные сущности: MP3 загружается отдельно, а постоянные метки следует вносить в `data.js` после прослушивания записи. Сайт предназначен для семейного вечера, но GitHub Pages и Cloudinary остаются публично доступными по ссылкам.
